Sparse attention changes the rule of dense attention that every token may attend to every earlier one. In sliding-window attention, each token attends only to the most recent few thousand positions. Other designs combine a local window with a few global tokens, use fixed strided or block patterns, or select positions dynamically.

A token outside the window is not lost. Each layer passes information forward by up to one window, so stacking layers lets information travel much further, indirectly. Several open models alternate local-window layers with full-attention layers to get most of the saving while keeping some direct long-range reach.

Sparse attention is entirely internal to the transformer. It decides which positions already in the context each token may look at, and it is fixed by the architecture. It does not search a document collection, and it does not bring anything new into the context. That is what retrieval does, outside the model.
